O MyFinances é um sistema de gerenciamento financeiro desenvolvido em Java com Spring Boot. O projeto foi criado para praticar o desenvolvimento de uma aplicação back-end completa, trabalhando desde o cadastro e autenticação de usuários até a integração com banco de dados e implementação de recursos de segurança.

Funcionalidades

- Cadastro de usuários;
- Login com Recuperação de senha por e-mail;
- Criptografia de senhas utilizando BCrypt;
- Validação de e-mail;
- Geração de códigos de verificação;
- Registro de gastos;
- Registro de entradas;
- Integração com banco de dados SQL Server.

Tecnologias 
- Java; 
- Spring boot; 
- Spring Data JPA;
- Spring Security; 
- pring Validation; 
- Spring Mail; 
- Maven; 
- Servidor 
- SQL Server;
- BCrypt; 
- Hibernate; 
- Metodologia Kanban;

Estrutura do projeto O projeto é organizado utilizando uma separação entre controladores, serviços, modelos e repositórios.
